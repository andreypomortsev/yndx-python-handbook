## [Виртуальный кликер](../../../solutions/4.1/41_e.py)

Допустим, вы создаёте онлайн-кликер — игру, где каждое нажатие увеличивает счёт.\
Реализуем основу такой игры на Python.

Создайте две функции:

- `click()` — увеличивает значение счётчика на 1;
- `get_count()` — возвращает текущее значение счётчика.

### Примечание

В решении не должно быть вызовов функций.

<details>
<summary>Подсказка</summary>

В первую очередь создайте глобальную переменную:

```python
count = 0
```

Дополнительно в имени можете поставить два нижних подчеркивания в начале:

```python
__count = 0
```

В Python такая переменная будет считаться приватной.

Опишите функции:

```python
def click():
    ...
```

```python
def get_count():
    ...
```

В первой функции вам потребуется изменить значение переменной, для этого воспользуйтесь директивой `global`. Она свяжет переменную в локальной области видимости с глобальной переменной.

```python
global __count
```

Во второй функции вам требуется только значение переменной, поэтому необходимости в директиве `global` нет.

</details>

### Пример 1

__Ввод__
```python
print(get_count())
click()
print(get_count())
```

__Вывод__
```plaintext
0
1
```

### Пример 2

__Ввод__
```python
click()
click()
click()
print(get_count())
```

__Вывод__
```plaintext
3
```
