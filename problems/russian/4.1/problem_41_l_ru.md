## [Поиск гор 2](../../../solutions/4.1/41_l.py)

Теперь давайте посмотрим на местность с высоты — словно вы летите на самолёте.\
Перед вами — прямоугольная таблица с высотами.\
Внутри этой сетки тоже могут встречаться «горы» — точки, которые выше всех своих соседей по 8 направлениям.

Создайте функцию `find_mountains(data)`, которая принимает список списков чисел и возвращает кортеж пар номеров всех гор.\
Нумерация начинается с 1 (по строкам и столбцам).\
Края таблицы считаются окружёнными горами бесконечной высоты, поэтому в них гор быть не может.

### Примечание

Ваше решение должно содержать только функции.\
В решении не должно быть вызовов требуемых функций.

<details>
<summary>Подсказка</summary>

Опишите функцию:

```python
def find_mountains(data):
    ...
```

Вычислите размеры списка:

```python
n = len(data)
m = len(data[0])
result = []
```

Организуйте перебор по потенциальным горам, используя итератор product:

```python
for i, j in product(range(1, n - 1), range(1, m - 1)):
    if ...:
        result.append((i + 1, j + 1))  # +1 с учётом требуемой нумерации
```

В качестве условия рекомендуем воспользоваться функцией all:

```python
all(condition for k, t in product(range(i - 1, i + 2), range(j - 1, j + 2)))
```

где `condition` является проверкой того что `(i, j)` гора по сравнению с `(k, t)`.

</details>

### Пример 1

__Ввод__
```python
result = find_mountains([
    [1, 1, 1],
    [1, 2, 1],
    [1, 1, 1]
])
```

__Вывод__
```python
result = ((2, 2),)
```
