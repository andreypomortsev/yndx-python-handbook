## [Слияние](../../../solutions/4.1/41_r.py)

Финиш близко — всего две задачи!\
Теперь научимся объединять отсортированные коллекции в одну.\
Это важный шаг в алгоритмах сортировки и при обработке данных.

Напишите функцию `merge`, которая принимает два отсортированных по возрастанию кортежа целых чисел, а возвращает один из всех переданных чисел.

### Примечание

Ваше решение должно содержать только функции.\
В решении не должно быть вызовов требуемых функций.\
_В этой задаче отключены стандартные сортировки_

<details>
<summary>Подсказка</summary>

Используйте метод двух указателей:

- Заведите два индекса (указателя), по одному для каждого кортежа
- На каждом шаге сравнивайте текущие элементы под этими указателями
- Меньший элемент добавляйте в результат и двигайте соответствующий указатель

</details>

### Пример 1

__Ввод__
```python
result = merge((1, 2), (3, 4, 5))
```

__Вывод__
```python
result = (1, 2, 3, 4, 5)
```

### Пример 2

__Ввод__
```python
result = merge((7, 12), (1, 9, 50))
```

__Вывод__
```python
result = (1, 7, 9, 12, 50)
```
